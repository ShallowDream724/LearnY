# 玻璃材质

`lib/core/design/glass_surface.dart` 只负责材质，不依赖路由、导航位置、课程或壁纸模型。背景来源始终是组件下方的实际页面，白色卡片和壁纸经过边缘时不会切换成两种取样来源。

## 组合与复用

| 部件 | 职责 |
| --- | --- |
| `GlassSurface` | 组合裁剪、底色、实时背景、内侧光影与外部阴影 |
| `GlassBackdrop` | 背景模糊、可用时的实时折射及可选色调映射；裁剪由调用方负责 |
| `GlassLighting` | 子内容下方的细腻反光，无背景、底色、内阴影或输入行为 |
| `GlassShadow` | 绘制表面外侧的柔和投影，可独立用于 `CustomPaint` |
| `GlassOptics` | 模糊、折射、光照和投影强度，与组件业务职责分离 |

圆角由 `radius` 指定，自动限制在短边一半以内；胶囊可传 `999`，其他工具栏、卡片或浮动按钮可传实际圆角。材质不固定高度、内容、点击区域或页面用途。例如：

```dart
GlassSurface(
  radius: 20,
  optics: const GlassOptics(refraction: 8, shadow: .7),
  child: Padding(padding: const EdgeInsets.all(16), child: toolbar),
)
```

底部导航的 `FrostedNavigationSurface` 仅选择胶囊形状。导航状态与跟手动画继续留在 shell。不要为了复用材质引入导航状态，也不要为新组件复制 shader 或光照常量。

## 光学与资源

`glass_refraction.frag` 对真实背景按圆角形状连续位移取样。`glass_light.frag` 使用距离场、表面朝向和高斯衰减生成细窄、轻柔的反光；不绘制内侧暗环，也不以等宽描边模拟玻璃。厚度由细腻的反光与外侧投影共同表达，白色内容经过玻璃时保持内部通透。外侧投影使用高斯衰减，侧边比上下稍宽，接触阴影和远处投影均保持轻量。光影画在图标和文字下面，避免洗淡前景。

每个表面只有一个有界背景过滤层，折射与模糊由引擎在 GPU 合成；不对页面逐帧截图、CPU 读回或单独重画壁纸。shader 程序按资产缓存，每个材质实例独立拥有并释放可变 shader。加载失败时保留可用的底色、背景模糊和内容。

Flutter 3.41 的 `ImageFilter.shader` 仅支持 Impeller。运行时检查 `ImageFilter.isShaderFilterSupported`，Skia（包括 Windows 与普通 widget 预览）使用实时背景模糊，内侧光影 shader 仍可使用。高对比模式改用实底并禁用透光与光影。不能把 widget 预览当作 Android 折射效果的截图；设备预览入口见 [UI 预览](../tool/ui_preview/README.md)。

## 导航与阅读表面

导航按下时抬升放大透镜，拖动使用保留速度的弹簧跟踪，松手后按位置与有限速度投影提交目标页；取消回到当前页。图标在透镜内外分别裁切，避免双影。语义与焦点热区独立于绘制，键盘可直接选择。减少动态效果时立即停止弹簧并直接定位。交互参考 FLClash Android 导航，代码独立实现，未复制其 GPL 源码。

build 35 修复白色卡片下选中透镜难以辨认的问题。`NavigationGlassAppearance` 只管理导航的语义前景、栏体色调和选中色调，不拥有几何或交互。栏体适度压缩实际背景的明暗范围、保留色相；选中透镜在浅色主题略深、深色主题略亮，带克制的靛蓝倾向和静止时可见的柔和投影。色调连续跟随实际滚动内容，不根据单点采样突然反色。按压和速度形变维持已有行为。

色调通过 `GlassSurface.backdropTone` 合成进同一个背景过滤层，位于折射/模糊之后、前景之前。Impeller 与 Skia 模糊回退共用 `ColorFilter`，没有新增截图、CPU 读回、轮询或页面重建；色调矩阵按主题缓存，按压帧复用栏体组件。高对比模式保留语义色的实心选中形状，并禁用透光。方向参考 [Apple：Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/) 对调节亮度范围、选择性着色和自适应材质的说明，属于 Flutter 独立实现。

渲染回归覆盖浅/深主题各五类底色（白、黑、蓝、米色、暗红），测量输出像素，保证选中面与栏体的可见区分、图标对比以及背景变化仍能传入材质。此检查使用 Skia，不替代 Android Impeller 的真机观感复核。

课程玻璃与导航分别处理：`StudyLightScene` 使用已解码壁纸的保守色彩范围，按课程表面的位置求保护量；不逐帧读回像素。结果缓存上限 128 项。壁纸强度使用感知映射保留原图色彩，自定义图像按视口量化解码并限制最长尺寸 2560。普通标题与短标签不再执行逐位置保护查询。

build 38 删除主页标题背后的壁纸切片和渐变保护。普通首页、作业、课程、设置标题随内容一起滚动；工具栏保留裁剪，不再向下一张卡片伸出绘制。课程整理模式单独保留实底固定工具栏，使取消与完成始终可达，范围严格限于工具栏。`StudyHeaderContent` 给页面标题的字形提供 2 dp 小范围光影，动作使用各自有界的 Material 底色与主题前景；不把标题保护铺成横条。

## 正文取色准确性与资源边界（build 36）

原来的 16×32 缩小取样只用于系统栏图标亮度提示，不作为课程玻璃文字对比判断的依据。`wallpaper_contrast_grid.dart` 在工作 isolate 中扫描已解码图片的全部像素，把每个区域的 RGB 最小/最大值保存在至多 32×64 格、12 KiB 的范围表中。这样细纹理或单个暗像素不会被平均值抹去；通道范围是保守界限，可能比精确字形取样多保留一些保护量。

查询与壁纸绘制共用裁剪、缩放和定位算法，包含下采样滤波范围；透明像素、用户壁纸的深色处理和强度混合均计入。先聚合区域的字节范围，再计算一次对比保护，避免逐格执行重复的亮度转换。分析缺失时按主题使用最不利的背景界限，不靠平均色猜测文字可读性。

完整像素分析最多一个任务正在执行，切换时只排队最新图片；旧结果不能覆盖新场景。GPU 读回与像素缓冲只发生在图片加载时。没有重新解码时，窗口变化只改变区域映射；自定义图跨过解码尺寸分档时会作为新图片分析，仍受串行合并约束。系统栏的小图取样仍随视口更新。分析字节通过 `TransferableTypedData` 交给临时 isolate，结束后仅保留范围表；读取用的图片 clone 在读回完成后释放，原始缓冲不进入持久缓存。内置图像像素缓冲约 6 MiB，自定义解码上限对应单份缓冲至多 25 MiB，创建传输数据时有短暂副本；该边界不等于整个应用的内存上限。

## 有界操作面（build 38）

build 37 给标题和短标签绘制的外侧 36 dp 白色渐变，在实际滚动中形成黏连与覆盖。该方案已撤销，`StudyReadableContent`、`StudyReadingGroup`、`ReadingFeather` 和标题壁纸切片均删除，不继续通过扩大渐变或降低透明度修补它。

`StudyControlSurface` 为真正的功能控件提供有明确边界的圆角材质：首页统计入口、作业摘要/筛选、分组折叠和退出登录。填色只在控件布局范围内合成，不使用背景模糊、离屏蒙层或向外扩散的彩色渐变。语义前景在保留色相/饱和度的前提下调整亮度，材质固定为白色或深蓝灰的 240/255 alpha，避免滚动或不同壁纸导致闪变；所有课程语义色及退出红色对最不利的白/黑背景合成检查至少 4.5:1。此保证适用于这些有界控件，不把字形光影宣称为任意复杂壁纸上的严格文字对比证明。

设置分组名称直接属于已有的 `SettingsGroup` 阅读面板，采用与行内容一致的 20 dp 内边距。分组折叠的名称、计数和箭头组成一个操作面，计数不再叠套小卡片。页面标题留在滚动内容平面；底部导航保持原有玻璃交互与色调策略。

公开资料提供分层原则而非私有实现规格：[Apple WWDC 2025](https://developer.apple.com/videos/play/wwdc2025/219/) 将玻璃用于导航功能层、提醒避免玻璃层互相套叠，并把滚动边缘处理限定于内容穿过悬浮控制的关系；[HarmonyOS 模糊使用指南](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/ui-use-blur-efficiently) 区分模糊、亮度、饱和度与遮罩，不能用白色颜色渐变冒充真实背景渐变模糊；[HONOR MagicOS](https://www.honor.com/cn/magic-os/) 展示操作材质与实际场景光线相连。LearnY 本轮采用其层级原则，未声称复刻系统私有算法。
