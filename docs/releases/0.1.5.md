# LearnY 0.1.5

2026-10-06 · build 41 · Windows x64 / Android

## 界面与操作

- **课程浏览**：常规手机宽度下采用双列课程卡片，大字号仍按可用空间调整。
- **作业阅读与提交**：要求默认展开；桌面并列查看要求和编辑内容，手机按阅读、编辑、附件、提交的顺序操作。提交按钮紧邻编辑区，未保存修改保留退出确认。
- **玻璃导航**：支持按下放大、连续拖动和取消，选中位置随页面横滑移动；键盘出现时收起，详情返回保留原浏览位置。明暗主题下的选中面更容易辨认。
- **壁纸与文字**：重做透明阅读层，修复高清手机上的重复纹理和像素台阶；轻量高斯模糊保留壁纸细节，保护范围跟随文字和图标，滚动时平滑淡出，点击区域保持原尺寸。
- **细节修复**：作业状态标签的首字、标题、截止时间与正文对齐；设置分组名称归入所属面板，普通页面标题自然滚动；清除重新提交正文中的 HTML 注释残留；未读文件类型筛选居右，返回时先关闭菜单。

## 登录、课表与资源

- 自动重新登录完成校园接续后再发布登录状态，保留信任设备选择；遇到学校二次认证时停止重复密码提交。
- 教务临时失败时保留已有课表，缩短重试等待并自动恢复查询。
- 同步和排课元数据最多同时处理三门课程，空闲位置立即处理下一项，减少慢课程造成的等待。
- ZIP 预览在后台流式处理并校验，合并重复解压；限制 PDF 图像缓存，暂停隐藏页面动画并释放旧网络客户端。

## 下载与安装

- **Android**：下载 `LearnY-0.1.5-android.apk` 安装，签名延续 0.1.4，可覆盖升级。
- **Windows x64**：下载 `LearnY-0.1.5-windows-x64-portable.zip`，完整解压后运行 `learn_y.exe`，保留同目录的 DLL 和 `data/`。
- `SHA256SUMS.txt` 提供两端安装包的 SHA-256 校验值。

两端生产构建、静态检查和相关回归测试已通过。具体测试范围与 Android 渲染的验收边界见 [本次验收记录](https://github.com/ShallowDream724/LearnY/blob/v0.1.5/docs/VALIDATION_2026-10-06.md)；校园会话和此前功能的验证见 [前次记录](https://github.com/ShallowDream724/LearnY/blob/v0.1.5/docs/VALIDATION_2026-10-05.md)。
