# LearnY 0.1.5 build 37

本地候选版本，2026-10-05。未发布到 GitHub Release。

这次更新集中处理课程双列、作业阅读与提交、自动登录收尾、短暂教务失败恢复，以及文件预览资源占用。桌面作业页可并排查看要求和编辑内容；手机直接显示要求。底栏加入按压放大和可取消的连续拖动，背景根据文字区域调整遮光而保留壁纸颜色。

build 33 将课程排课元数据与各类课程内容同步统一到有界任务队列，最多同时处理三门；空闲位置立即处理下一项，慢课程不再阻塞整批。

build 34 进一步重组作业工作区，将编辑、附件和提交收在一起；移除主页顶栏整行增白遮罩；修复编辑器注释残留，并补齐底栏与滚动、键盘、详情返回和手势中断的协作。界面观感与设备手感按用户最新安排由用户复核。

build 35 修复悬浮底栏在浅色卡片上选中状态不清的问题。明暗主题各有克制的选中色调，并随真实背景连续变化；保持现有按压、拖动和页面协作，高对比模式保留实心选中形状。

build 36 统一作业身份与卡片正文的左边线，并为首页彩色统计增加主题色阶和柔边局部对比保护。背景分析按保守区域范围处理细纹理，使用串行后台任务与有界缓存。

build 37 将同一阅读保护扩展到课程整理、作业筛选/分组、设置分组和退出登录。文字与图标下方保持均匀保护，渐隐发生在内容区域外侧；标题栏允许柔边向外绘制，重叠滚动内容时保留连续遮挡。未读文件类型按钮居右，菜单接入系统返回，关闭不再等待页面退出转场。

验证证据与限制记录在 [本轮验收](../VALIDATION_2026-10-05.md)。真实短信触发由学校身份系统决定；离线流程测试和一次成功课表读取不能代表已覆盖所有网络或认证故障。Android 真机的折射效果仍需设备验收。
