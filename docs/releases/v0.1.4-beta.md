# LearnY v0.1.4 Beta

本次同时提供 Windows x64 免安装版与 Android APK，应用版本为 `0.1.4-beta+23`。

## 下载与使用

- **Windows**：下载 `LearnY-0.1.4-beta-windows-x64-portable.zip`，完整解压后运行 `learn_y.exe`。请保留同目录的 DLL 和 `data/`。校园登录需要 WebView2 Runtime。
- **Android**：下载 `LearnY-0.1.4-beta-android.apk` 安装。
- `SHA256SUMS.txt` 提供安装文件的 SHA-256 校验值。

## 主要更新

- Windows、Android 与平板界面适配，加入玻璃课程卡片、分平台背景和背景强度设置。
- 课程支持 20 色自动避重与手动配色，保留自定义图标、简称和排序。
- 完善日／周课表与学期切换，缓存内容在网络不可用时仍可查看。
- 修复网络学堂会话失效后自动重登未触发；校园会话跨日期复用，快捷登录失败后可回退密码登录，并限制重复提交。
- 修复 PDF／ZIP 首次下载后的预览时序问题。
- 改善课程页面稳定性，以及作业、通知和文件的日常操作。

这是 Beta 预发布版。PDF／ZIP 预览已收到人工确认；最新校园会话恢复与配色已通过针对性检查，真实网络切换和设备观感仍需进一步使用反馈。
