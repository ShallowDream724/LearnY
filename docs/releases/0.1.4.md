# LearnY 0.1.4

0.1.4 正式版提供 Android APK 与 Windows x64 免安装版，当前为修订构建 31。本次更新集中完善校园登录、整学期课表、文件阅读和手机界面，并将两端的课程身份与学习操作统一到共享组件。

## 课表与学期

- 周课表保留从早八开始的空课时段和课程之间的间隔，按实际分钟绘制课程位置与长度。中途开始、跨多个大节、不同结束时间和同日重叠的安排都能按时间对齐，只收起最后一节课之后的空白。
- 全周无课的 12:15–13:30 用紧凑「午休」带呈现；有课跨过时保持真实时间比例。课程块只显示课名和地点，完整时间可点击查看，手机可上下滚动浏览晚课。
- 已知教学范围按整学期获取并缓存，翻周共享请求。教务确认的空日、空周保持为空，不再叠加网络学堂推算课程。
- 区分正在浏览的学期、网络学堂启用学期与校历教学学期。校历数据独立维护并记录官方来源，保留节假日、考试周与跨年边界。
- 修复展开未读文件时混入其他学期；首页摘要与完整列表使用同一学期范围。

## 登录与同步

- 修复校园 OAuth 成功回调、教务失败页面识别及登录／退出时的状态生命周期问题，复用已有身份恢复校园访问。
- 自动恢复根据学校实际响应处理会话失效，并合并并发请求、限制重复密码提交；普通网络超时不会直接触发密码登录。
- 补齐作业、通知分页与课程文件列表的完整性检查，避免用不完整响应覆盖本地数据。

## 界面与个性化

- 手机采用悬浮玻璃导航，选中位置连续跟随左右滑页；壁纸延伸至系统栏与导航下方，明暗模式分别调整光影。
- 支持上传自定义壁纸、框选裁剪、缩放、强度预览与重新裁剪，外观入口统一放在“我的”。
- 课程支持 20 色自动避重、手动配色、自定义图标、简称与排序；首页、课程详情、文件分组和搜索共用课程身份。
- 首页课表以日期为标题，日期与右侧操作保持同排；待办的闹钟和小时数靠右。首页统一刷新学习内容与课表，周课表保留独立刷新。
- 作业总览与课程详情统一呈现分数、批改及提交状态，作业分组可折叠。

## 文件与图片

- 修复 PDF、ZIP 首次下载后需要切换信息页才能预览的问题。
- 统一各入口的文件类型图标、收藏、阅读状态、分享与外部打开操作。手机文件和通知支持长按菜单。
- 通知、作业要求、反馈和图片附件支持长按保存原图到相册。
- Office 文档继续交给系统选择的应用打开。

## 下载与升级

- **Android**：安装 `LearnY-0.1.4-android.apk`，构建号 31，可覆盖更新此前版本。
- **Windows x64**：下载 `LearnY-0.1.4-windows-x64-portable.zip`，完整解压后运行 `learn_y.exe`。这是免安装可执行版；请保留同目录 DLL 和 `data` 文件夹。
- `SHA256SUMS.txt` 提供两个下载文件的 SHA-256 校验值。
