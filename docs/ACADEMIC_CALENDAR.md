# 教学校历维护

Learn 的学期目录用于识别、选择学期；教学校历用于定位开学日、教学周和课表范围。二者不能混用。2026-09-12 实测 `getCurrentAndNextSemester` 返回秋季 `kssj=2026-09-12`、`jssj=2027-02-14`，而官方本科校历为 2026-09-14 至 2027-01-17。将前者所在自然周作为第一周会错误定位到 9 月 7 日。

## 数据与职责

- `assets/calendar/academic_terms.json` 是已核实的教学日期数据，随应用发布。
- `AcademicCalendarCatalog` 校验版本、学期 ID、日期、来源、重复项和同一学生类别的重叠范围。
- `AcademicCalendarSource.load()` 是来源接口；目前由 `BundledAcademicCalendarSource` 读取资产。
- `AcademicCalendar` 只处理日期归属，不访问网络，也不猜测未知学期。
- `CalendarRangeRepository` 按已确认范围读取整学期教务事件，保存为每周缓存；界面和排课推算共用同一校历。

隔离示例环境显式注入自己生成的教学日期夹具，不把示例学期元数据或真实账户数据混入正式校历。生产入口只读取校历来源接口。

目前没有实现自动获取学校教学校历的 API。检查到的[官方校历页面](https://www.tsinghua.edu.cn/zjqh/syxx/qhxl.htm)使用年度图片，所检查的公开页面与参考客户端未发现结构化教学日期接口。这不等于学校不存在其他接口。

## 后续维护流程

1. 从官方入口打开对应年度校历，核对本科／研究生、正式上课日、考试周和假期，不能仅根据图片文件名判断年份或使用范围。
2. 在 JSON `terms` 中添加或修正对应条目：`id`、`audience`、`start`、`end`、`source`、`verifiedOn`、`note`。保持 `schemaVersion: 1`；核验日使用实际日期，备注记录周中开学或特殊教学安排。
3. 运行 `flutter test test/core/semester/academic_calendar_catalog_regression_test.dart`。日期有业务变化时补充相关边界回归；数据来源和本表同步更新。
4. 提交日期表、文档和必要回归，构建新版本。当前方案需要应用更新后才能收到新日期，不具备远程热更新。

缺失条目不会退回 Learn 的启用日期，也不外推历史或未来学期；保留绝对日期浏览和已有教务快照，停用没有可信边界的周次推算。资产加载失败也使用这一退化路径，不阻止应用启动。

以后若取得可靠的结构化接口，实现新的 `AcademicCalendarSource`，统一经过目录校验再注入即可；日期导航、排课推算和缓存仓储无需分别接入新接口。若增加远程发布的数据表，应再明确来源信任、版本、缓存与离线回退，不把这些职责放入界面。
