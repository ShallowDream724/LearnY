# LearnY 设计体系

## 产品基准

LearnY 是每天反复使用的学习工具。一次打开应迅速知道当天的安排、需要处理的作业，以及新到的课程资料。完整任务包括进入、辨认、操作、等待、完成和返回；各环节共同决定体验质量。界面的精致来自这些环节协同成立，包括动作的范围清楚、内容真实、操作及时响应、退出后仍能继续刚才的事。

参考 Emil Kowalski skills 的全部 12 份指南与 7 份配套文档。具体来源、适用条件与应用记录见 [设计资料研读](DESIGN_REFERENCE_REVIEW.md)。参考其信息组织、即时反馈、空间关系、可打断过渡、合理默认值与细节一致性；Web 渲染规则、指定库和物理参数按 Flutter 重新评估。

本文件描述已确认的产品要求与设计方向。2026-09-07 已整合首页、作业、课程、文件、搜索、登录与设置的界面及共享交互；真实 Flutter 预览与必要行为检查补充集成证据，设备手感和学校服务仍由项目负责人验收。后续 PDF/PPT 阅读能力与 AI 工具接口单独迭代。

## 信息与布局

- 导航、当前学期和同步状态属于应用上下文。学期选择明确影响范围；同步应自动完成，必要的手动刷新放在其作用范围能被理解的位置。不能仅为容纳控件而增加常驻横栏或侧栏区域。
- 页面标题中的学期表示正在浏览的范围；选择器分别标注按校历确定的「当前教学学期」与网络学堂报告的当前学期，学校提前开放新学期不代表已经开课，不自动改掉用户选择。
- 首页保持每日课表入口，独立周窗口不更改首页学期或日期。跨学期规则遵循 SCHEDULE_DESIGN.md。
- 首页日程直接以「周几 · 月/日」为标题并可点击选日期。手机用滑动切日，标题区依次安排非今天时的「回到今天」和「周课表」，不再重复展示左右箭头与局部刷新。首页下拉和顶栏刷新覆盖学习内容与当前课表；周弹层保留自己的刷新。
- 宽屏利用并列区域缩短阅读和返回路径；窄屏按任务重要性纵向组织。布局依据扣除侧栏等区域后的实际可用宽度，操作入口依据鼠标、键盘和触控能力。窗口缩放、平板旋转与大字号仍须保持任务路径。
- 空状态不展示没有决策价值的占位信息。筛选结果为空时保留筛选入口；整个学期为空时给出学期上下文。请求失败不等同于空数据。目录中的资料总数可保留零值，按具体浏览任务判断。
- 列表、正文与阅读器按内容分别确定密度和阅读宽度。长文需要受控行长，文件列表需要扫描与比较，课表需要时间位置关系，不能用同一最大宽度代替判断。页面区域用间距和分隔组织，独立重复项目才使用卡片。禁止装饰性左侧竖条。

## 完整任务

| 场景 | 首要信息与操作 | 连续性与状态要求 |
| --- | --- | --- |
| 首页 | 当天时间、地点、下一步待办 | 每日课表保持紧凑；少课不撑高，密集数据不挤掉其他学习任务 |
| 周课表 | 一周安排、切周、局部学期、回到当前时间 | 独立浏览范围；支持便捷退出；取消跨界确认留在原周 |
| 作业 | 需要处理什么、截止时间、提交状态 | 逾期单独分组；筛选为空仍可解除；提交页截止时间常驻，要求正文直接展开；宽屏并列要求与编辑区域，窄屏顺序阅读；成功回执主动退出，未保存修改退出前确认 |
| 课程与详情 | 课程身份、通知、作业与资料 | 打开和返回保留列表位置、查询与范围；长标题和元数据有明确换行策略 |
| 文件与阅读 | 文件身份、可用内容、当前主要动作 | 下载进度、缓存、失败恢复有连续状态；不在不同位置重复同一组工具 |
| 搜索 | 查询、结果分组、定位内容 | 分组菜单过滤结果；请求错误可重试，空结果可改词；快速改词不被旧响应覆盖；离开详情回来保留查询与位置 |
| 登录与设置 | 完成登录、必要的个人选择 | 校园服务会话自动协调；人工验证按真实需要出现；常规技术细节不成为用户任务 |

该表约束任务关系，不冻结最终布局，也不新增尚未确认的业务功能。

## 视觉与输入

- 明亮的淡靛底色与白色内容表面，深色采用有色相的深蓝灰底层。靛蓝承载操作，课程使用稳定的柔和色彩身份；提醒、失败、成功单独表达状态。应用标识采用已确认的日晷原稿，Windows、Android、登录和侧栏使用同一身份；原稿与导出方式见 [品牌资源](../tool/brand/README.md)。颜色通过主题与 `StudyPalette` 定义，不在各页复制调色盘。课程提供 20 个明暗主题配套色，同学期自动优先使用空闲颜色；保存后保持稳定，支持在整理课程中自选。课程卡片、详情、课表、作业、文件、通知与搜索共用身份，规则见 [课程颜色](COURSE_COLORS.md)。
- 文字靠字号、字重、行距和对比建立主次。中文、时间和数字共同排版，不以淡小字掩盖重要信息。时间、计数的更新不应引起横向跳动；字体放大时布局能重新排布，不能只缩小文字或截断关键内容。
- 应用声明简体中文区域并使用 Flutter 官方中文本地化。两端随包内置未经修改的霞鹜文楷 GB 屏幕阅读版；屏幕版本身已增强笔画，不再靠大量粗体建立层级。主题和独立文字样式共用 `AppFont` 与 `AppTypography`；来源、版本和许可证见 `assets/fonts/README.md`，应用设置提供开源许可入口。原始字体完整保留，避免课程、人名或通知中的字符因子集化缺失。
- 真实选择、悬停、按压与焦点分别呈现。选中导航或筛选保留明确的前景与表面区别，普通行使用克制的反馈。设置由整体分组面板承载，行内有独立水平内边距与分隔；外观控件位于行尾。鼠标关闭外观菜单后不保留焦点填色，键盘关闭后保留原控件焦点。自动登录的完整诊断收进详情，常规页面保留摘要、开关和恢复入口。
- 按钮和可点击项目提供可辨认的按压、悬停、焦点、禁用状态。按下立即反馈，普通动作在有效抬起后执行，移开可取消。反馈可用状态层或其他合适方式，不要求所有项目缩放。图标操作有提示。手机列表的已读操作仅由未读项左滑触发，不放置常驻按钮；已读项目可从详情恢复未读。桌面每行左侧只有一个已读/未读按钮，以信封表达阅读状态，不使用容易误解为任务完成的对号；通知的重要标记保留在内容右上角。不以鼠标拖动模拟左滑。
- 弹层支持明确的退出路径，保留触发位置或浏览上下文。鼠标菜单、对话框和大课表各自采用合适的层级与遮罩；嵌套弹层的关闭顺序明确。键盘焦点可进入、可返回；减少动态效果时可采用清楚的静态反馈。
- 手机正文图片、放大图片和图片附件共用长按菜单，可保存原图到系统相册；保存中防止重复提交，成功或权限/空间不足时给出对应反馈，关闭图片返回原阅读位置。
- 文件条目长按或右键使用同一菜单，提供收藏、阅读状态、分享与外部打开；通知长按可切换阅读状态并沿用列表撤销。已读项仍不触发手机左滑动作。首页待办的更多按钮只在桌面显示，手机使用长按。弹出菜单使用应用顶层导航／覆盖层，避免菜单自动定位选中项时带动主页面横滑。
- 材质用来解释层级：浮在内容之上的工具可以有适当半透明，普通页面无需装饰性毛玻璃。遮罩、阴影、边缘和文字对比应协同；深色、繁杂背景与低性能设备都要能成立。
- Windows 与 Android 共用壁纸、材质和语义前景的对比策略：保留壁纸色彩，按功能层选择材质厚度，小字始终可读，不依赖整屏灰罩、普遍描边或厚重文字阴影。用户的壁纸强度不取消可读性底线；明暗主题分别调配。此项为 2026-09-14 确认的后续方向，完整区域自适应尚未实现；来源与边界见 [设计资料研读](DESIGN_REFERENCE_REVIEW.md)。
- 「我的」页头像使用简洁人物图形，不截取姓名或账号首字；账号名称在旁边独立显示。

## 动效与状态

背景切换仅放在「我的 → 使用偏好 → 背景」。桌面默认为「晴岚」，另有「澄光」「远山」「微光」；Android/iOS 使用独立竖版原图，默认为「澄光」30%，另有「暖丘」「远山」「碧潭」。默认背景与选择器排列顺序分别配置，已有选择和各图强度继续保留。素材集合按设备平台选择，不随窗口缩放或旋转切换；手机不裁切桌面原图。点缩略图即时应用并保存，可在同一选择面板中连续比较，点击空白或关闭返回。每幅背景独立保存 0–100% 强度，拖动时即时预览，松手保存；0% 隐藏、100% 呈现当前明暗主题的完整图像。背景资产的原色、构图与阅读面遮光量分别配置，不把一张图的调色规则套到所有图上。背景贯通首页、作业、课程、设置与外壳；课程卡片采样共享背景，其他页面保留各自的内容面板。

同一背景面板支持一个自定义图片槽。导入后默认按实际屏幕比例居中取景，可移动选框、拖动四角、双指或滚轮缩放，也可选择原图、横竖或方形比例；强度与主题效果可在应用前预览。取消不改当前背景，应用后保留原图副本供重新裁剪；移除只删除应用管理的副本。Android 状态栏透明，图标深浅根据顶部背景与强度选择，不以黑色罩覆盖壁纸。

- 页面切换与状态变化立即响应，过渡不阻塞合理的下一次操作。高频列表不逐项延迟出现。可中断元素从当前屏幕位置继续，手势松开时依据实际场景传递速度；不能从已经过时的逻辑端点重新播放。
- 动效按用途选择：按压反馈、内容替换、导航、弹层、直接拖动具有不同的时序和生命周期。`AppMotion` 的常量只可视为普通场景起点，不构成全部动效的规格。骨架与页面过渡遵循减少动态效果设置。
- 同一个操作的反馈保持连续。下载或同步已经在原位显示状态时，避免又堆叠多条提示；完成、取消与失败有不同结果。已读操作立即保存，未读列表以淡出与高度收拢承接数据移除，手机保留左滑位置并提供一次轻触觉反馈。每个列表共用一行内联结果与撤销入口，连续操作合并计数；不逐条弹出成功提示，不抢焦点，不阻塞其他条目。最后一项退出后再显示空态，撤销入口继续保留。减少动画时仍保留静态结果反馈。防止重复提交由业务操作状态负责，不能用转场期间锁住整个界面代替。
- 本地正在看什么与后台正在请求什么有明确所有权。切学期、换账号或更新搜索后，旧请求不能覆盖新范围；重试与后台更新尽量保留仍有用的内容。
- 加载中、成功无数据、筛选无结果、暂时离线、缓存过期和请求失败需要不同恢复路径。课表来源与不确定时间继续遵守 [课表设计](SCHEDULE_DESIGN.md)，不能用美化后的统一空态抹平这些差异。

## 实现与验收

### 构图与几何

- 首页宽屏以 5:3 的内容区域分配日程/待办与通知/文件；窄屏保持每日课表、待办、更新的阅读顺序。这个比例服务于各列实际信息，并非通用比例模板。日程保留紧凑的日视图，日期与控制集中在同一标题区；单门课使用横向内容关系，仍保留课程色底。
- 首页每列面板撑满分配宽度，内容较短或为空时不收缩；面板宽度由首页布局统一约束。
- 首页待办、未读通知与未读文件面板的底部内边距为 12，减少最后一项及空状态下的多余留白；顶部、左右内边距及条目之间的间隔维持各自的信息层级。
- 待办标题区使用占满面板内容宽度的一行布局，左侧为标题，最右侧为可点击的闹钟图标与「X 小时」；点击可调整显示范围。逾期项始终纳入，全部待交入口独立保留；大字号下标题可在自身区域折行，范围仍在右侧。
- 未读文件课程分组与课程页共用默认／自选图形。文件列表、筛选和详情统一使用 `FileTypeUtils` 的图标与颜色，不混用扩展名字母纸片。文件信息页底部延续阅读背景，外部打开用主色实心按钮，分享用描边按钮。
- 课程卡片使用淡彩玻璃与课程图形：标题占完整行宽，教师右侧安排图形，身份区与统计区之间保留细分隔。待交、未读按真实状态显示，资料数量保留零值，避免同组卡片因统计缺失而失去排列关系。外边距保护文字，同排高度按真实内容与操作区测量，宽卡不按固定宽高比增高。课程颜色与课表同源，图形库、自选流程与默认匹配遵循 [课程图形规范](COURSE_ICONS.md)。
- 作业、文件与搜索控制阅读宽度。作业总览与课程详情共用同一自适应作业卡。右侧优先呈现结果：数值成绩使用突出字号加「分」，不重复附「已批改」；等级直接显示「已阅」「优秀」等原有语义，无成绩时显示提交／批改状态，不猜测满分或按百分制着色。桌面标题、日期、结果保持稳定列关系；手机将日期放在标题下，结果保留右侧；窄屏或大字号时移到下方右侧，避免挤压标题。未提交项目可点击状态、长按或右键调整本地提醒。作业分组标题整行可点按折叠，保留计数与展开状态提示；折叠状态按学期重置，筛选仍可独立使用。信息密集的列表不使用大面积装饰阴影，独立面板使用一致的边缘、填色与轻微光影。
- `StudySurface` 负责通用面板与可选交互，不决定业务状态或列表几何。外壳的 `StudyLightBackdrop` 负责一幅共享光影背景，`CourseGlassSurface` 负责课程玻璃的内面和边缘；取色来自背景的实际位置，不逐卡片进行布局后测量，不叠加背景模糊。键盘、指针和触控反馈沿用 Flutter 的语义与输入机制。2026-09-09 的背景试用覆盖外壳与四个主页面，保留布局、课程颜色与图形；详情与阅读页仍使用独立阅读面。原图、竖屏取景和深色试用版本见 [光影背景](../tool/artwork/README.md)，实际观感由项目负责人在 Windows/Android 验收。
- 手机底部导航使用悬浮胶囊，只常显四个图标，名称由长按／悬停提示和读屏语义提供。选中透镜随页面的连续滑动进度移动，手势反向或取消时同步回退；显式点击从当前显示位置过渡到新入口，减少动态效果时直接定位。壁纸延伸到系统手势区，胶囊四周留空。边缘与中心透出同一份实时页面背景；阴影向外渐隐、反光向内扩散，强度随弧面和光照方向非线性变化，左右暗影稍宽，上下更细，避免均匀描边。支持的渲染器对实际背景做曲面折射，兼容模式保留模糊与弧面光影；边缘不单独覆画壁纸，经过白色卡片时仍自然衔接。材质封装在可复用的 `GlassSurface` 及其独立部件中，导航只指定胶囊形状。日间采用透光乳白与深色前景，夜间采用烟灰底和亮色前景，高对比模式使用实底。课程卡片继续使用原有光场绘制。列表末尾避让实际导航高度，输入键盘出现时收起导航；系统状态栏与手势栏按各自位置的壁纸取色选择深浅图标。

玻璃的轻盈感优先于厚重的立体边框：反光细窄、投影克制，内部不额外叠加暗环。尤其在白色内容上，避免形成外暗边、白边、内暗边多层套叠的观感。

选中状态不能只依靠白色透镜叠加白色内容。底栏的选中面保持淡色调与轻微明度差，明暗主题分别调配；透过来的真实内容颜色连续影响材质，同时限制明暗范围以保障图标可读。着色集中在选中状态，不把整个导航变成主色实底，也不以突然反色处理滚动边界。高对比模式使用清楚的实心选中形状。

留白必须能解释内容关系。标题与边界之间的呼吸空间、不同任务之间的间隔，与固定高度剩下的空洞不是同一件事。字库、字号、行高、内边距与真实内容一起决定几何；单独换色或增加圆角不能证明整页成立。

2026-10-05 第二轮界面复核：作业工作区在桌面左侧保留身份、紧凑截止时间和展开的要求，右侧按编辑、附件、核对、提交排列在同一写作面内。主要操作紧邻其作用内容，不再放在跨整窗的底部白条；窄屏沿同一操作链纵向排列，使用页面滚动避让键盘，退出修改仍需确认。长要求单独滚动，桌面身份与截止时间留在左上方。验收必须包含只有一个要求附件的稀疏作业、长正文和较矮窗口。

四个主页共用 `StudySliverAppBar`：背景重绘同位置壁纸，文字与操作区分别按实际前景色获得必要的柔边对比保护，不再给整行顶栏统一增白。以正在使用的壁纸和强度检查背景连续性；默认壁纸预览不能代替复杂背景检查。

build 36：作业身份、截止时间和倒计时与要求卡片内的正文共用 20 dp 左边线，状态标签的外轮廓沿该线排列；详情、提交编辑、手机和桌面由同一几何常量管理。首页统计保留彩色数字，按主题微调色阶并与柔边局部阅读底共同保证对比；仅在内容组附近保护文字，原有入口、数字密度和字重不变。背景对比依据已解码图片的保守区域范围，精度和资源边界见 [玻璃材质](GLASS_MATERIAL.md)。

悬浮底栏在纵向浏览时保持可用，内容末端避让胶囊。页面横滑、底栏预览和路由提交有统一协调：松手才切页、竖向滑出取消、再次选中当前页能结束未完成的页面滑动。详情盖住外壳，返回保留滚动；键盘出现时收起底栏，隐藏分支不接收焦点。

共用颜色、字体、输入组件与基础呈现放在 `lib/core/design`；导航与响应式外壳放在 `lib/core/shell`；页面组合内容并绑定业务动作。认证、同步、学期和提交继续由业务模块负责。共用组件封装真实重复的行为，不把每种空态、列表或弹层硬塞进一个不断增加布尔开关的万能组件。

先把完整任务与关键状态在真实 Flutter 界面里做通，再把经得起使用的共性收敛为组件，逐步推广到其他页面。跨页面改动需在信息密度和返回行为上一起审视，不能靠各页分别换样式完成整合。

必要验证包括受影响的业务边界、静态检查，以及少量实际 Flutter 布局与交互预览。真实校园会话、设备手感与实际提交由项目负责人验收。不得把 HTML 原型或模拟数据截图称为真实业务验证；已验证单元及时提交，未完成的 UI 草稿不包装成发布版本。
