# 课表浏览

## 用户任务

首页首先回答当天有什么课、在哪里上，并给作业、通知和文件留下空间。手机、平板和 Windows 都保持每日入口；查看整周时打开独立的大弹层。

## 呈现规则

- 每日入口按时间显示全部课程。只有一门时用一列，多门用紧凑两列；窄宽度或大字体自动改为单列。点击已匹配课程直接进入详情，未匹配课程仍可查看完整时间地点。
- 周表按天分列、按时间对齐，保留全部课程，超出高度可纵向滚动。较长的无课间隔压缩，同一时段的不同课程并排。稀疏课表不会拉伸色块填满窗口。
- 教务提供准确结束时间时使用正常矩形。仅有大节编号时只显示开始时间，按两小节的名义长度绘制，底边为锯齿；第二大节按 09:50 至 11:25 绘制。不会根据学分推断时长。
- 周末有课则保留，无课则自动隐藏；显示选项允许始终显示周末。日视图可以直接访问任何日期。
- 周弹层支持左右滑动、前后周按钮、日期选择、回到今天、关闭按钮、Esc 和点击弹层外的空白区域退出。周表翻页不改变首页正在查看的日期。
- 首页每日课表跟随首页所选学期；切换已知日期的历史或未来学期时定位首日，当前学期默认定位今天。到学期末日后不能继续滑出，向外滑动或点击后一天会询问是否切换首页学期。确认后保存首页学期并进入下一学期首日，课程、作业等一起切换；取消停在原日。
- 周弹层初次打开定位今天所在周，拥有独立学期选择。选择非当前学期定位包含开学首日的自然周，选择当前学期回到本周。学期末周没有可继续滑入的页面，继续向后滑或点击下一周时询问是否切换课表学期；确认才进入下一学期第一周，取消停在原周。此操作不修改首页日期、首页学期或持久化的学习学期。
- 反向跨界同样确认，确认后定位上一学期末日或末周。学期间存在假期时直接定位相邻学期边界；起止日期未知的学期不可猜测定位，也不会跳过它进入更远学期。
- 日期选择器限定在当前浏览学期内；周弹层通过学期选择入口或回到今天改变浏览学期。边界自然周只展示所选学期内的课程和待安排提醒。跨午夜仍停在所选学期末日，不自动改变首页学期。
- 请求结束后必须结束加载；无缓存、请求失败、教务空响应和排课推算都有明确语义。已有推算课表时，次要的教务授权失败不会遮挡课程。
- 未排课或无法完整解析的安排显示独立提醒，保留原文并可进入课程。部分已排课、部分待安排的课程同时出现在两处。

## 日期与数据

按周一至周日查询，每周独立缓存和冷却。同周切日复用数据；翻页边界来自已确认的学期起止日期，不取决于是否有课。未知学期日期时保留绝对日期浏览能力，不编造边界。日期范围可打开日期选择器，跨年份浏览时显示年份。

课表是教务系统的日期日历，学习学期选择是课程、作业、通知和文件的浏览范围。底层课表查询不要求两者相等，界面按用户意图区分首页切换与弹层局部切换。旧版按学习学期拦截日历请求会导致开学前无法查看新学期安排，已取消这一请求条件。远端是否已发布某一天的数据仍由教务系统决定。

`AcademicCalendar` 负责日期归属，学校返回的起止日期优先，集中维护的已核实校历补齐缺失信息。已维护夏季至 2026-09-13、秋季从 2026-09-14 至 2027-01-17；来源为学校公开校历。未知或冲突的日期边界不自行外推。

日期所属学期的课程目录由 `CourseCatalogRepository` 获取，与学习内容当前选择无关。目录 15 分钟后可自动刷新，手动刷新立即重新获取。成功返回的课程列表是权威选课集合，新增课程立即参与排课推算；请求失败保留现有课程。

教务已在该周提供某课程时，该课程整周采用教务安排，以保留节假日移课。尚无教务安排的课程采用网络学堂排课，注明未包含节假日调课；不能由空数组推断学校确实没有开课。成功空响应保留此前教务快照，避免历史数据丢失。

教务快照与排课推算分开存储和计算。选课目录删除课程后，当前及未来的旧教务记录会被过滤；已确认退课的课程名称索引可过滤随后返回的滞后教务记录。过去的教务记录保留。没有可靠名称或 ID 关联的记录保留原始安排，不猜测其是否已退课。

周次解析支持范围、枚举、单双周、中英文格式。空星期、第 0 节、超范围或无法完整识别的表达进入待安排提醒，禁止悄悄丢弃未识别部分。

## 认证

网络学堂和教务授权分别处理。教务客户端跟随受限的 HTTPS OAuth/WebVPN 重定向，兼容 WebVPN 内层 `/https/` 转 `/http/`，外层传输仍为 HTTPS。Windows 的 WebView2 和 Android 原生 CookieManager 可读取 HttpOnly Cookie，校园授权入口将它们按服务主机导入 Dio，再验证真实教务请求。iOS 尚未补齐原生 Cookie 导出，不能视为已支持此授权流程。

2026-09-07 的现场检查中，完成 WebVPN 登录后，夏季当周、秋季首周和历史春季周曾返回 HTTP 200 空数组；秋季网络学堂有 5 门含排课的课程。教务根页面同时存在“登录超时或内容不存在”的模糊提示，因此不能仅凭空数组断言课表未发布或会话有效。后续复查已观察到 WebVPN 要求重新认证，网络学堂会话仍然有效。

使用正式 `ScheduleRepository`、应用现有网络学堂会话及独立内存数据库完成了端到端验证：2026-09-14 所在周生成周二 2 门、周三 1 门、周四 2 门安排，共 5 门，来源为排课推算，无未识别条目。该路径不依赖诊断浏览器的 WebVPN 会话。

## 验收

自动检查覆盖跨周及跨年日期、鼠标与键盘、手机滑动、一周 35 节课、稀疏周、空周末、放大文字、失败与缓存、请求取消、账户清理、选退课、调课优先级及未排课提醒。离线截图由真实 Flutter 组件和本机字体渲染，输出到 `build/ui_preview/`。原生认证视图和实际输入手感仍需设备验收。
