# 课表浏览

## 用户任务

首页首先回答今天有什么课、在哪里上，以及这周哪些天有课。用户还可以查未来或过去的周、跳到具体日期，或进入已匹配课程的详情。课表应给作业、通知和文件留下空间。

## 呈现规则

- 日视图按时间排列，显示开始与结束时间、课程名和地点。窄屏默认预览三节，可展开剩余课程；宽屏以两列紧凑排列当天课程。
- 内容宽度足够时默认周视图。通常按天分列，每天预览三节，更多课程通过计数入口进入当天；整周不超过三节且集中在一两天时，自动改为带日期的紧凑清单。课程分散在多天时保留列布局，避免清单反而增加高度。
- 手机和较窄平板默认日视图，周模式以每天的课程摘要呈现。布局依据可用宽度与文字大小，不能仅按操作系统决定。
- 周末仅在已有课表数据、没有正在更新或错误、且该天无课时自动隐藏。宽屏可选择始终显示周末。手机日视图保留七天入口，避免隐藏日期使当天无法直接选择。
- 空周只显示简短状态。缺少缓存和请求错误有各自状态；成功返回空数组才可表示已确认无课。数据加载不占据一个固定的大内容容器。
- 课程没有可靠的详情关联时仍显示真实安排，不给它编造跳转目标。完整名称和地点也可通过悬停查看。

## 日期与数据

按周一至周日查询，每周独立缓存和冷却。同周切日复用数据；前后周按钮不受已有课程数量或六天窗口限制。日期范围可打开日期选择器，跨年份浏览时显示年份。

课表是教务系统的日期日历，学习学期选择是课程、作业、通知和文件的浏览范围。两者不互相阻止查询。旧版把两者相等作为日历请求条件，会导致开学前无法查看新学期安排，已取消这一条件。远端是否已发布某一天的数据仍由教务系统决定。

本地课程用于补全教务日历缺项。发生同课程、重叠时间的冲突时以日历为准，并保留已确认的课程详情关联；无法确定为同一课程的记录不合并。

## 验收

自动检查覆盖跨周及跨年日期、鼠标与键盘、手机滑动、一天六节课、稀疏周、空周末、放大文字、失败与缓存、请求取消和账户缓存清理。离线截图以真实 Flutter 组件和本机字体渲染，输出到 `build/ui_preview/`；学校未来课表、真实登录和输入手感需人工验收。
