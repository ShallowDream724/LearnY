# 背景与选择

2026-09-09 使用项目负责人提供的原图，背景贯通首页、作业、课程、设置与应用外壳，供实际设备比较。课程玻璃采样共享背景，其他内容面板及详情、阅读页面保留各自的阅读表面。

桌面提供「晴岚」「澄光」「远山」「微光」，没有已保存选择时默认晴岚。build18 加入手机专用的「暖丘」「澄光」「远山」「碧潭」，默认暖丘。首页、课程页右上角的「更换背景」按钮与「我的 → 使用偏好 → 背景」共用同一选择器；点缩略图立即应用并保存，选择器保持打开以便连续比较，点空白、关闭按钮、系统返回或 Esc 退出。遮罩透明，预览保留实际页面亮度。

`StudyWallpaper` 管理稳定 ID、名称、平台集合与阅读面遮光量；`WallpaperArtwork` 管理每份原图的资源和取景。`mobileWallpapersProvider` 在 Android/iOS 选择竖版集合，不依赖窗口宽度，旋转和缩放不会改换素材集合。旧选择在当前平台不可用时回到该平台默认值。`wallpaperProvider` 管理 app_state 中的设备外观偏好，登录退出和换账号不清除；快速连续选择按顺序写入，启动时的历史读取不能覆盖用户的新选择。图像解码前保留原背景，加载完成后统一替换页面与卡片的光场。

背景强度为每个背景分别保存的 0–100 整数，默认 30%。滑杆拖动即时更新共享光场，松手持久化；0% 只显示主题底色，100% 显示当前明暗主题的原图版本。切换背景恢复各自的强度。选择与强度保存失败时保留当前预览并提示。

手机四份竖版原稿分别位于 `source/warm_hills_mobile.png`、`source/prism_mobile.png`、`source/alpine_mobile.png`、`source/cove_mobile.png`，均按用户提供文件原样保存。浅色无损导出保留 RGB，深色沿用曝光派生流程；手机不会使用桌面原图裁切。缩略图为 192 × 416，选择面板按可用宽度和字号排为最多四列；设置页也使用竖版缩略图。远山与碧潭的阅读表面遮光稍多。

三张新图在 `source/prism.png`、`source/dunes.png`、`source/alpine.png` 原样留存，浅色导出保留原始 RGB，不应用「微光」的去黄与压缩反差处理。每幅图分别生成深色曝光版本与 384 × 216 的选择缩略图；深色为本地派生版本。远山的阅读表面遮光稍多，减弱岩石、树林对文字的干扰。

`assets/artwork/source/glass_landscape.png` 保留提供的 1672 × 941 原图。`export_light_scene.py` 从原稿派生浅色、深色的 WebP，使用无损编码。build15 根据实际设备反馈收敛大面积暖黄，保留局部暖反光和较清楚的冷色反射；浅色通过单调亮度曲线抬起暗边、收敛背景反差，颜色与亮度分开处理，避免一层去饱和灰雾。深色保持原有曝光关系并采用同样的色彩收敛。两幅图都是派生调色，不是另一次生图。Flutter 只打包各背景的浅色、深色 WebP 与小尺寸缩略图，原图与导出工具不进入安装包。

```sh
python tool/artwork/export_light_scene.py
```

工具依赖 NumPy 与 Pillow，本机使用 conda `aider` 环境。

`StudyLightBackdrop` 在应用外壳统一加载图像；`StudyLightScene` 缓存与窗口尺寸对应的纹理变换。各背景以 cover 为基础，按当前平台原图的取景配置平滑调整，保持原图比例。「微光」继续放大 1.16 倍并靠近左上取景，让曲面向右下退让；手机使用独立竖版构图。课程卡片在绘制时取得其在共享背景中的位置，内面与边缘采样同一纹理，边缘略有折射位移。不存在逐卡片资源加载、布局后测量或背景模糊。窗口外的滚动缓存与边缘采样使用 clamp，避免出现颜色断层。`StudyLightSurface` 让滚动标题栏绘制同一位置的完整背景，避免内容滚到标题下方时透出文字。

图像加载和主题更换通过 inherited scope 更新保留页面中的卡片，旧 ImageInfo 依照 Flutter Image 的方式在帧结束后释放。深色使用相同构图，避免主题切换后光源与形体位置改变。

真实 Flutter 预览可用 `tool/ui_preview/course_icons_preview_test.dart` 的 `LEARNY_PREVIEW_SCENE_ONLY` 参数，覆盖 Windows 与手机浅深色、两端选择器、手机切换及独立强度保存。实际设备观感由项目负责人直接检查，不以截图代替设备验收。
